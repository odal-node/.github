# Support

The project is pre-production and has one maintainer. There is no support contract,
no SLA and no paid tier. This page lists where a question is most likely to be seen,
not how fast it will be answered.

## Where to ask

| You want to | Go to |
|---|---|
| Learn what the software does or how to use a crate | [docs.odal-node.io](https://docs.odal-node.io) |
| Ask a question or discuss an approach | **Discussions** on [dpp-core](https://github.com/odal-node/dpp-core/discussions) or [dpp-engine](https://github.com/odal-node/dpp-engine/discussions) |
| Report a bug | **Issues**, in the repository where the bug is |
| Request a feature | **Issues**, in the repository it belongs to |
| Report a security vulnerability | **security@odal-node.io**, never a public issue. See [SECURITY.md](SECURITY.md) |
| Hear when managed operation opens | [The waitlist](https://odal-node.io/waitlist/) (an email address, not a form) |
| Anything else | **contact@odal-node.io** |

Ask in public where you can. An answer in an issue or a discussion helps everyone who
searches later.

## What makes a question answerable

- **The repository and version.** A commit SHA is better than a version number, and
  both are better than "the latest".
- **What you ran and what happened.** The exact command and the exact output.
- **What you expected instead, and why.** If you think the software is wrong about EU
  law, cite the text you read. That is the most useful kind of report.

## What this project cannot provide

- **Compliance advice.** Nothing here is legal advice, and no output of this software
  proves that you comply with anything. The software assembles and signs a passport.
  Whether the passport meets your obligations is between you, your notified body and
  your national authority.
- **Support for a deployment we do not operate.** Every node runs on its operator's
  own infrastructure, and we have no access to it. We do want the bug report.
- **A conformance claim.** Where the code implements a standard, its documentation
  states what it implements and what it does not claim. Read that before you rely on
  it.

## The websites

`odal-node.io` and `docs.odal-node.io` carry documentation, schemas, vocabulary and
**demonstration** passports. They host no operator's data and no production service.
Real passports are served by each operator's own node, on the operator's own domain.
